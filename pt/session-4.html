Terça-feira, 8 de dezembro · 09:30 – 10:30
  • 09:30
    STAC2Cube: A Python Library for Automated Construction of Earth Observation Data Cubes from INPE STAC Collections
    Matheus Rodrigues (Instituto Nacional de Pesquisas Espaciais), Evandro Rodrigues (Instituto Nacional de Pesquisas Espaciais), Bruna da Silva (Instituto Nacional de Pesquisas Espaciais), Rennan Marujo (Instituto Nacional de Pesquisas Espaciais), Camilo Rennó (Instituto Nacional de Pesquisas Espaciais), Fábio Gama (Instituto Nacional de Pesquisas Espaciais), Thales Korting (Instituto Nacional de Pesquisas Espaciais), Gilberto de Queiroz (Instituto Nacional de Pesquisas Espaciais)
    Resumo

    STAC2Cube is a Python library for automated construction of Earth observation data cubes from collections available through INPE’s SpatioTemporal Asset Catalog (STAC) service. It integrates data querying, spatial filtering, variable classification, harmonization to a common grid, overlap aggregation, and provenance recording in an xarray-based structure. Interoperability was evaluated using 18 data configurations, of which 16 produced complete cubes with spatial resolutions from 8 to 64 m. Cube sizes ranged from 70.86 MiB to 24.87 GiB, with execution times between 22.37 and 1,593.64 s. The results indicate that STAC2Cube provides a reproducible workflow for heterogeneous INPE STAC collections.

    Improving the WTSS Python Client: Evolutionary Maintenance and a Monthly NDVI Composite Case Study
    Suellen de Almeida (ITA), Rennan Marujo (INPE), Karla Fook (ITA)
    Resumo

    This paper presents improvements to the Python client of the Brazil Data Cube Web Time Series Service (WTSS). The redesign includes time-indexed pandas and xarray outputs, raster export, improved HTTP handling, automated testing, and spatial and interactive plots. To test the client, a case study evaluates polygon-based retrieval and a monthly NDVI composite using 23 Sentinel-2 composites covering 88,682 pixels in Mato Grosso. After quality masking and temporal aggregation, the monthly raster was written with rasterio using the grid reconstructed by the client. The analysis also identified server-side inconsistencies and limitations caused by cloud-contaminated observations.
